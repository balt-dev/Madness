# Madness

Brings the absurd lack of balance from mods like Cryptid or Mayhem to vanilla items.

Takes some code from Cryptid, and code from VanillaRemade.

# Licensing (or, the lack of it)

Unfortunately, there's no proper way to license this code.

Cryptid is under the GPL. However, VanillaRemade is intentionally left unlicensed, so this code cannot be licensed, but that is in violation of the GPL.

I would rather violate Cryptid's code license than violate Balatro's code license, so this code has been left unlicensed.

Cryptid's license has been left as `LICENSE-CRYPTID` at the root of the repository.

To the Cryptid developers: sorry. :P
